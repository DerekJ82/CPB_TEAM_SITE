Google Chat Webhooks

Webhook URLs are stored as Script Properties — not hardcoded. To rotate a URL, update the value in Apps Script project settings. To rename a key, update both the property and the corresponding Code.gs reference. Note: CHAT_WEBHOOK_URL_Billy uses mixed case — match exactly when referencing in code.

🔔
Authy

Fires whenever someone requests access to the CPB Hub, posting a real-time notification to the team Chat space so approvals never sit unread. Property: CHAT_WEBHOOK_URL_AUTHY

🔔
Flashy

Notifies team members when the Flash Flasherson context doc is ready to fill out, keeping everyone in sync at the start of each Flash cycle. Property: CHAT_WEBHOOK_URL_FLASHY

🔔
Billy (CBR Bot)

Billed Revenue dashboard bot. Posts CBR pipeline updates to the team Chat space. Property: CHAT_WEBHOOK_URL_Billy

🔔
Blake

IPP team task bot. Alerts the Chat space when tasks go overdue, flags completions, and supports ad-hoc team broadcasts. Property: CHAT_WEBHOOK_URL_BLAKE

🔔
Larry

WLS Nets process monitor. Surfaces issues as they arise and notifies the Chat space when records are archived or key process events occur. Property: CHAT_WEBHOOK_URL_LARRY
