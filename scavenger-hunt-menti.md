## HOW TO USE

1. Create a new **Quiz** presentation in Mentimeter (menti.com).
2. Add each slide below in order. Slide type is listed per clue.
3. For **Select Answer** slides: enter all four options exactly as written — the ✅ marks the correct one.
4. For **Type Answer** slides: Mentimeter will show a word cloud; call out the accepted answer(s) listed.
5. Set a timer (suggested **60–90 seconds** per clue) so people race to find it.
6. Use the **Host Reveal Note** to screen-share the actual page/card as you reveal each answer.

## MENTIMETER SETUP TIPS

- **Presentation mode:** Set to "Quiz Competition" for a leaderboard after each question.
- **Timer:** 60 s for Select Answer clues, 90 s for Type Answer clues.
- **Pacing:** Read the question aloud, start the timer, then share your screen on the relevant site so early-finishers can verify — but don't navigate to the answer yet.
- **Reveal:** After time's up, screen-share the Host Reveal location before moving to the next slide.
- **Join slide:** Add a Menti title slide at the start with the 6-digit code and menti.com URL displayed large.
